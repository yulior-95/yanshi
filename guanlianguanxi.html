账户关联规则说明

1. 直接关联（Hop1）

设备MAC 相同 → 结论「疑似同人（高置信）」，仅供参考、非最终认定。同登录 IP / 登录环境直接命中、无中间户 → 结论「同环境关联」，一般不视为疑似同人。

2. 按时段看流水

在追踪时长内，分别列出付款方的收入/支出和收款方的收入/支出。每笔写清对手；再标明该对手与订单付款方、收款方有没有关联。

3. 混合入账

收款方除订单本金外还有无关来源汇入时，标一下即可，不硬拆比例。

4. 与身份关联配合

关联结论来自①账户关联。资金页只回答：这笔对手跟付款方有没有关联、跟收款方有没有关联。

订单资金追踪规则说明

1. 从订单出发

输入订单号→拿到下单时间与交易类型→设定追踪时长。每笔流水都保留自己的订单号与类型。

2. 交易类型

私聊红包、群聊红包、私聊转账、群聊转账、埋雷红包、接龙红包、交易区、汇兑区、地址转账。普通类型看付款方/收款方两侧后续流水。

3. 汇兑区（特殊）

汇兑区是自己跟自己的交易（如 USDT 兑换成 C币）。查询后不再分收付款双方，只追踪兑换账户本人在追踪时长内的其他交易。

4. 关联判断

关联结论来自①账户关联。资金页标对手与查询相关方（付款方/收款方，或汇兑区本人）有没有关联。
