应用概述：

这款加密聊天应用提供安全的通信解决方案，支持一对一聊天、群聊、语音/视频通话等功能，同时确保所有通信内容端到端加密。


用户体验分析（短信异常痛点）
  1. 在弱网、海外、运营商拦截场景下，短信验证码延迟或丢失导致登录、注册、交易中断。
  2. 交易环节对时效要求高，需要脱离短信通道的稳定二次验证能力。
  3. 用户更希望可自主管理验证方式，并且在切换时有明确风险提示。

产品界面设计策略
  1. 在我的-安全设置新增“谷歌验证码”入口，提供独立设置流程。
  2. 设置流程拆分为“密钥复制页”和“安全验证码页”，确保首次绑定路径清晰。
  3. 手机/邮箱/谷歌三种交易验证方式按详情页管理，支持互斥切换与异常拦截。

核心功能：
  1. 安全加密通信（一对一聊天、群聊）
  2. 语音/视频通话支持
  3. 完善的群组管理功能（公告、成员管理）
  4. 丰富的消息类型支持（文本、图片、语音、视频、文件）
  5. 个人资料和隐私设置
  6. 在线客服支持
  7. 交易验证码三选一互斥策略（谷歌/手机/邮箱）

指定群开放 · 群聊交易全流程
  1. 发起（卖方）：选买家 → 卖出币种/数量 → 成交汇率 → 自动算出买家应付人民币 → 支付宝/微信/银行卡收款方式 → 时长 → 密码冻结放币。
  2. 买方付款：按订单人民币金额，向卖方收款账户转账；「我已付款」「取消付款」均需两步确认。
  3. 卖方放币：核对人民币到账后「我已收到」两步确认，立刻放币（无需买方先点已付款）。
  4. 超时：买方未付款 → 自动退卖家；买方已付款卖方未放币 → 买方可申诉。
  5. 后台：申诉单列表与审核（通过放币 / 驳回退卖家 / 要求补证）。

直播数据后台
直播观看数据统计 · 后台管理（市场部 / 领导查阅）
  1. 使用对象：市场部与管理层，用于复盘单场及多场直播的观看质量。
  2. 核心指标：进入人数、不足 1 分钟退出人数及占比、长时间观看用户（≥30 分钟）、整体平均观看时长。
  3. 时长分层：观看不足 1 分钟退出；超过 5 / 10 / 30 分钟的人数及占比；并提供互斥区间分布条便于结构解读。
  4. 场次对比（应对场次多）：顶部时间范围 / 直播时间范围 / 群组UID / 主播编号 / 群主编号 / 快捷筛选（高流失、优质场次等）；趋势图叠加每场进入人数与所选指标；明细表可排序分页，勾选最多 4 场做并排对比并标注最佳。
  5. 单场详情：每项指标同时给出与当前周期均值的差值（环比 / pt 差），可用上一场 / 下一场快速翻阅。
  6. 导出报表：点击后直接生成真实 .xlsx 文件（场次明细 / 汇总指标 / 指标口径说明三个工作表），导出内容等于当前筛选与排序结果。
  7. 口径文档：live_admin_stats_metrics.html 以 Markdown 形式列出每个数值与百分比的计算公式、加权规则、阈值与常见误区，支持复制原文或下载 .md。

直播打赏
直播打赏 · 体验与信息架构（浅色 / C币 / 半屏直播）
  1. 用户需求：在半屏群直播场景下，用统一虚拟货币 C币 完成打赏；余额不足时跳转钱包充值；赠送要有明确视觉反馈与榜单荣誉。
  2. 核心交互：播放器内打赏按钮 → 浅色底部 Sheet（可用余额 + 礼物单价为 所需 C币）→ 校验余额 →（充足）确认数量与合计 C币；（不足）浅色「余额不足」面板 → 去钱包充值 / 更换礼物 → 成功后触发送礼动画 + 弹幕 + 聊天礼物气泡。
  3. 榜单：主播打赏榜统计观众对当前主播的累计送礼（C币）；群成员打赏榜统计本群内成员送礼横向排名，可与前者并存。
  4. 视觉规范：页面主体为白/浅灰（#f8f9fa / #fff），主色与消息模块对齐（#1890ff）；弹窗一律浅色；仅播放器画面区为深色沉浸。
  5. 工程：live_reward_proto.css 统一变量与组件；独立 HTML 便于 iframe 评审；送礼动画见 live_reward_gift_fx_demo.html（可替换 Lottie）。

用户体验分析摘要：打赏是高频冲动消费，需降低认知成本（单一币种 C币）、失败路径短（就地提示差额）、成功路径有仪式感（动画 + 公屏露出 + 榜单）。

产品界面清单：直播半屏页、礼物 Sheet、余额不足 Sheet、确认赠送 Sheet、成功反馈页、动画演示页、双排行榜页；顶栏模拟 iOS，底部保留 Tab Bar 与主 App 一致。
