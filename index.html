iToken 小程序
功能说明：

iToken 是独立于主应用的安全验证小程序，类似微信小程序的架构设计。即使主APP出现问题，用户的设备绑定信息和验证功能仍然安全可用。


架构优势：
  1. 风险隔离 - 主APP被报毒/下架不影响iToken的设备绑定关系
  2. 数据安全 - 用户信息、设备信息、iToken关联存储在独立模块中
  3. 灵活更新 - iToken模块可以独立更新，不依赖主APP版本
  4. 硬件级安全 - 密钥存储于设备安全芯片，私钥永不离开设备

激活流程：
  1. 生物识别 + 手机验证码 → 发送激活申请给服务端
  2. 服务端返回激活许可 → 设备安全芯片生成密钥对
  3. 提交公钥和激活许可 → 服务端用根私钥签发证书
  4. 证书返回APP → 激活成功

绑定账号流程：
  1. 添加68账号（68号+密码 / 手机号+验证码 / 邮箱+验证码）
  2. 进行生物识别验证
  3. 绑定成功，显示该账号专属的 iToken 验证码
